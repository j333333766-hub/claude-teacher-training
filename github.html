클로드 코드 × GitHub

깃허브 연결하기

내 PC에서 만든 웹앱을 인터넷에 올려 주소 하나로 나눠 쓰는 방법입니다. 한 번만 연결해 두면 그다음부터는 클로드에게 “올려 줘” 한마디면 됩니다.

무엇을 하나요코드를 깃허브에 보관하고, GitHub Pages로 무료 게시합니다.
걸리는 시간처음 한 번 15분쯤. 그다음부터는 1~2분.
필요한 것윈도우 PC, 클로드 코드, 이메일 주소 하나.

1깃허브 계정 만들기 한 번만

  1. github.com/signup에서 이메일로 가입합니다.
  2. 사용자 이름(username)은 게시 주소에 그대로 들어갑니다. 예: 사용자이름.github.io/저장소이름
  3. 무료 요금제(Free)를 고릅니다.

이미 계정이 있으면 이 단계는 건너뜁니다.

2도구 두 가지 설치하기 한 번만

Git(변경 내용을 기록하는 도구)과 GitHub CLI(깃허브를 명령으로 다루는 도구)가 필요합니다. 클로드 코드에 시키면 됩니다.

깃(Git)과 깃허브 CLI(gh)가 설치되어 있는지 확인하고, 없으면 설치해 줘.

직접 설치하려면 파워셸에 한 줄씩 넣습니다.

winget install --id Git.Git -e
winget install --id GitHub.cli -e

설치한 뒤에는 파워셸 창을 닫았다가 다시 열어야 명령이 잡힙니다.

3깃허브에 로그인하기 한 번만 · 직접 해야 해요

로그인은 브라우저에서 내가 직접 승인해야 합니다. 새 파워셸 창을 열고 아래 명령을 넣습니다.

gh auth login

물음이 차례로 나옵니다. 방향키로 고르고 Enter를 누릅니다.

물음고를 것
Where do you use GitHub?GitHub.com
Preferred protocolHTTPS
Authenticate Git with your GitHub credentials?Yes
How would you like to authenticate?Login with a web browser

화면에 8자리 코드가 나옵니다. Enter를 누르면 브라우저가 열리고, 그 코드를 넣은 뒤 Authorize를 누르면 끝입니다.

잘 됐는지 확인합니다.

gh auth status

“Logged in to github.com account …”가 보이면 연결된 것입니다.

4클로드에게 올려 달라고 하기

클로드 코드를 열고, 올릴 폴더 경로를 알려 준 뒤 이렇게 말합니다.

이 폴더를 깃허브에 새 저장소로 올리고, GitHub Pages로 게시해 줘. 게시된 주소도 알려 줘.

클로드가 저장소 만들기 → 파일 올리기 → Pages 켜기를 차례로 하고 주소를 알려 줍니다. 주소는 이런 모양입니다.

https://사용자이름.github.io/저장소이름/
  • 첫 화면이 될 파일 이름은 index.html이어야 합니다.
  • 올린 뒤 실제로 열리기까지 1~2분 걸립니다.
  • 저장소 이름은 영어·숫자·하이픈으로 짓습니다. 클로드에게 “저장소 이름은 ○○로 해 줘”라고 정해 줘도 됩니다.

5고친 뒤 다시 올리기

방금 고친 내용을 깃허브에 올려 줘.

바뀐 파일만 올라가고, 같은 주소에 1~2분 뒤 반영됩니다. 브라우저에서 옛 화면이 보이면 Ctrl+F5로 새로 고칩니다.

어제 상태로 되돌려 줘.

깃허브는 올릴 때마다 기록을 남기므로, 잘못 고쳤을 때 이전 상태로 돌아갈 수 있습니다.

올리기 전에 꼭 확인하세요
  • 무료 계정의 GitHub Pages는 공개 저장소에서만 됩니다. 올린 파일은 누구나 볼 수 있습니다.
  • 학생 명렬표, 연락처, 성적, 사진은 올리지 않습니다.
  • API 키와 비밀번호가 든 파일은 올리지 않습니다. 클로드에게 “올리기 전에 개인정보나 키가 들어 있는지 확인해 줘”라고 먼저 시키세요.
  • 한번 올린 내용은 지워도 기록에 남을 수 있습니다.

?막혔을 때

gh, git 명령을 찾을 수 없다고 나와요

설치한 뒤 파워셸 창을 새로 열지 않았을 때 생깁니다. 창을 닫고 다시 엽니다. 클로드 코드도 껐다가 다시 켭니다.

winget이 없다고 나와요

학교 PC에서는 막혀 있을 수 있습니다. git-scm.com과 cli.github.com에서 설치 파일을 받아 설치합니다.

주소를 열면 404가 나와요

대개 아직 반영 중이거나, index.html이 저장소 맨 위에 없을 때입니다. 클로드에게 “Pages 게시 상태 확인해 줘”라고 말합니다.

학교에서 깃허브 접속이 안 돼요

학교 망에서 막혀 있으면 집이나 휴대폰 핫스팟에서 올립니다. 게시된 주소를 여는 것은 대부분 됩니다.
