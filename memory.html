규칙과 기억 쌓기

같은 설명을 매번 되풀이하지 않으려면 규칙과 기억을 파일로 남겨 둡니다. CLAUDE.md, 메모리, 스킬 세 가지를 씁니다.

CLAUDE.md항상 지킬 규칙
메모리프로젝트별로 기억할 사실
스킬되풀이하는 일의 절차
구분무엇을 담나요예
CLAUDE.md언제나 지켜야 하는 규칙“저장·삭제·제출 단추는 누르기 전에 먼저 알려 줘”
메모리일하면서 알게 된 사실과 진행 상황폴더 위치, 배포 주소, 마감, 지난번에 틀린 것
스킬여러 단계로 된 일의 방법공문 제목을 주면 담당자를 찾아 주는 절차

1CLAUDE.md에 규칙 적기

클로드 코드가 시작할 때 가장 먼저 읽는 글입니다. 직접 쓰지 않고 말로 시키면 됩니다.

앞으로 문서를 고칠 때는 항상 백업부터 하고, 처음부터 다시 만들지 말고 해당 부분만 고친다는 규칙을 CLAUDE.md에 적어 줘.
위치적용 범위
작업 폴더의 CLAUDE.md그 폴더에서 일할 때만
내 계정 폴더의 .claude\CLAUDE.md모든 작업

실패한 일이 있으면 그 자리에서 “이 실수를 다시 하지 않도록 규칙으로 적어 줘”라고 말합니다. 규칙은 이렇게 쌓입니다.

2메모리에 기억시키기

이 프로젝트의 폴더 위치와 배포 주소, 다음에 할 일을 기억해 둬.
착수회는 10월 16일 13시야. 수정해 줘.
○○ 작업 기억해? 어디까지 했는지 알려 줘.

기억이 틀렸으면 바로 고쳐 달라고 합니다. 오래된 기억은 사실과 다를 수 있으니, 날짜와 수치는 한 번씩 확인합니다.

3스킬로 방법 저장하기

한 번 잘 된 방식은 스킬로 묶어 둡니다.

방금 한 방식을 다음에도 쓸 수 있게 스킬로 만들어 줘.
  • 스킬은 폴더 하나에 설명서(SKILL.md)가 들어 있는 모습입니다.
  • 설명에 적힌 상황이 오면 클로드가 알아서 꺼내 씁니다.
  • 함정과 주의할 점을 함께 적어 두면 같은 실수를 줄입니다.

4작업 기록 남기기

긴 작업은 하루를 끝낼 때 기록을 남겨 두면 다음 날 바로 이어 갈 수 있습니다.

오늘 작업한 내용, 파일 위치, 고치는 순서, 확인하지 못한 것, 다음에 할 일을 md 파일로 정리해서 이 폴더에 저장해 줘.
기억에 넣지 말 것
  • 학생 이름, 연락처, 성적 같은 개인정보
  • 비밀번호와 API 키 (키는 따로 둔 파일 위치만 기억시킵니다)
  • 남에게 공유할 문서에 서버 주소나 ID가 섞이지 않게 합니다
