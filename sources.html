클로드 코드 사용 ④

소스 가져오기

클로드 코드는 내 PC의 파일을 직접 엽니다. 그래서 파일을 올리는 대신 어디에 있는지(경로)를 알려 주면 됩니다. 경로를 빠르게 복사하는 법과, 클로드가 읽기 좋은 모습으로 자료를 준비하는 법을 모았습니다.

핵심파일을 설명하지 말고 경로를 붙여 넣습니다.
그림도갈무리한 그림도 경로로 줍니다.
한글 파일hwp는 hwpx나 PDF로 바꿔서 줍니다.
주고 싶은 것가장 빠른 방법
폴더 하나탐색기 위쪽 주소 칸에서 경로 복사 (1번)
파일 하나·여러 개오른쪽 단추 → 경로로 복사 (2번)
화면 갈무리·사진그림 파일의 경로 복사 (3번)
한글·오피스 문서AI소스변환기로 hwpx·PDF로 바꾼 뒤 경로 복사 (5번)
누리집 글주소를 그대로 붙여 넣기 (6번)

1폴더 경로 복사하기 탐색기 주소 칸

  1. 파일 탐색기에서 작업할 폴더를 엽니다.
  2. 위쪽 주소 칸의 빈 곳을 한 번 누릅니다. 폴더 이름들이 C:\Users\내이름\Documents\수업자료 같은 한 줄로 바뀌며 전체가 선택됩니다.
  3. Ctrl+C로 복사하고, 클로드 코드 창에 Ctrl+V로 붙여 넣습니다.

마우스 없이 하려면 Alt+D(주소 칸 선택) → Ctrl+C입니다. 주소 칸을 오른쪽 단추로 눌러 주소 복사를 골라도 됩니다.

C:\Users\내이름\OneDrive\2026학년도\수학과 폴더를 살펴보고 무엇이 들어 있는지 종류별로 정리해 줘. 아무것도 고치지는 마.

같은 주소 칸에 powershell이라고 쓰고 Enter를 누르면 그 폴더에서 파워셸이 열립니다. 여기서 claude를 시작하면 경로를 따로 주지 않아도 “이 폴더”라고 말할 수 있습니다.

2파일 경로 복사하기 오른쪽 단추 → 경로로 복사

  1. 파일(또는 폴더)을 오른쪽 단추로 누릅니다.
  2. 경로로 복사를 고릅니다. 단축키는 Ctrl+Shift+C입니다.
  3. 클로드 코드 창에 붙여 넣습니다. 경로가 큰따옴표에 싸여 들어갑니다.
"C:\Users\내이름\Documents\수업자료\1학기 평가계획.hwpx"
상황방법
윈도우 10이라 메뉴에 안 보일 때Shift를 누른 채 오른쪽 단추를 누르면 경로로 복사가 나옵니다
파일 여러 개를 한꺼번에Ctrl이나 Shift로 여러 개를 고른 뒤 경로로 복사. 한 줄에 하나씩 들어갑니다
마우스로 끌어서파일을 클로드 코드 창으로 끌어다 놓아도 경로가 들어갑니다

큰따옴표는 지우지 않습니다. 경로에 띄어쓰기나 한글이 있어도 따옴표 덕분에 한 덩어리로 읽힙니다.

"C:\…\평가계획.hwpx" 와 "C:\…\성취기준.xlsx" 두 파일을 읽고, 평가계획에 빠진 성취기준이 있는지 찾아 줘.

3그림도 경로로 주기 갈무리 · 사진

화면 갈무리나 사진도 파일이므로 같은 방법을 씁니다. 말로 설명하기 어려운 화면은 그림 한 장이 가장 빠릅니다.

  1. 윈도우+Shift+S로 필요한 부분을 갈무리합니다.
  2. 갈무리한 그림은 사진 → 스크린샷 폴더에 저장됩니다. (저장되지 않으면 화면 구석에 뜬 알림을 눌러 Ctrl+S로 저장합니다.)
  3. 그 그림을 오른쪽 단추로 눌러 경로로 복사합니다.
  4. 클로드 코드 창에 붙여 넣고 하고 싶은 말을 이어서 씁니다.
"C:\Users\내이름\Pictures\Screenshots\스크린샷 2026-10-10 153012.png" 이 화면에서 물음이 위에 따로 있어서 뭘 묻는지 알기 어려워. 식 바로 위로 옮겨 줘.
다른 방법설명
끌어다 놓기그림 파일을 창으로 끌어다 놓으면 경로가 들어갑니다
클립보드에서 바로 붙이기갈무리한 직후 Alt+V. 터미널에 따라 안 될 수 있어, 안 되면 경로로 줍니다
휴대폰 사진원드라이브·구글 드라이브로 PC에 내려받은 뒤 경로로 줍니다. 텔레그램을 연결했다면 사진을 봇에게 보내도 됩니다

그림을 여러 장 줄 때는 “첫째 그림은 지금 화면, 둘째 그림은 원하는 모습”처럼 무엇인지 함께 적습니다.

4클로드가 읽기 좋은 형식

형식읽기알아 둘 것
txt · md · csv · html아주 잘 읽음가장 정확하고 빠릅니다
PDF잘 읽음쪽수가 많으면 “3~10쪽만”처럼 범위를 말합니다. 스캔본은 그림으로 읽어 느리고 틀릴 수 있습니다
그림 (png · jpg)잘 읽음글자가 작으면 필요한 부분만 잘라서 줍니다
엑셀 (xlsx)읽음시트 이름과 머리글 줄을 알려 주면 정확해집니다
워드 · 파워포인트 (docx · pptx)읽음모양(배치)까지 봐야 하면 PDF로도 함께 줍니다
한글 hwpx읽음글과 표를 꺼내 읽습니다
한글 hwp바로 못 읽음hwpx나 PDF로 바꿔서 줍니다 (5번)
암호 걸린 파일못 읽음암호를 풀어 다른 이름으로 저장한 뒤 줍니다
영상 · 음성바로 못 읽음“자막을 뽑아서 읽어 줘”라고 시키면 글로 바꿔 읽습니다

5AI소스변환기로 한글 문서 바꾸기 AI소스변환기.hta

학교 문서는 대부분 hwp인데, AI는 hwp를 바로 읽지 못합니다. AI소스변환기는 폴더째로 골라 한꺼번에 바꿔 주는 작은 프로그램입니다. 내 PC에 설치된 한글·오피스로 바꾸므로 파일이 바깥 서버로 나가지 않습니다.

탭하는 일쓰는 때
HWP → HWPXhwp를 hwpx로 바꿉니다클로드 코드에게 한글 문서를 읽히거나 고치게 할 때
PDF로 변환한글(hwp·hwpx)·워드·엑셀·파워포인트를 PDF로 바꿉니다노트북LM·제미나이·클로드 앱처럼 파일을 올려야 하는 곳에 줄 때
  1. AI소스변환기.hta를 두 번 눌러 엽니다. 설치는 필요 없습니다.
  2. 위에서 탭을 고릅니다.
  3. 파일 선택 또는 폴더 선택으로 문서를 넣습니다. 하위 폴더까지 모두 찾기를 켜 두면 폴더 안쪽까지 한 번에 모읍니다.
  4. 저장 위치를 원본과 같은 폴더 또는 지정 폴더로 정합니다.
  5. 변환 시작을 누르고, 끝나면 결과 폴더 열기로 확인합니다.
  6. 결과 폴더의 경로를 복사해 클로드에게 줍니다.
C:\Users\내이름\Documents\2026 내부기안_변환 폴더의 hwpx를 모두 읽고, 문서마다 제목·날짜·담당자를 표로 정리해 줘.

소스용 사본은 지정 폴더에 따로 모으는 편이 좋습니다. 원본 폴더가 어지러워지지 않고, 그 폴더 하나만 클로드에게 주면 됩니다.

알아 둘 것설명
필요한 프로그램한글 문서는 한글, 워드·엑셀·파워포인트는 MS 오피스가 PC에 깔려 있어야 합니다
변환하는 동안한글·오피스가 뒤에서 실행됩니다. 편집 중이던 문서는 미리 저장합니다
암호 걸린 문서바뀌지 않고 실패로 표시됩니다. 암호를 푼 뒤 다시 넣습니다
같은 이름이 있을 때덮어쓰지 않고 이름 (1).hwpx처럼 새로 만듭니다
원본을 휴지통으로 보내기켜면 변환에 성공한 원본만 휴지통으로 갑니다. 처음에는 끄고 씁니다
멈추고 싶을 때중지를 누르면 하던 파일까지 마치고 멈춥니다. 한 번 더 누르면 강제로 끝냅니다
워드 문서에서 멈출 때PowerShell 7이 없는 PC에서는 워드 변환이 멈출 수 있습니다. 클로드에게 “PowerShell 7 설치해 줘”라고 시킵니다
두 번 눌러도 열리지 않거나 경고가 떠요

내려받은 파일은 윈도우가 막아 둘 수 있습니다. 파일을 오른쪽 단추로 눌러 속성을 열고, 아래쪽 차단 해제에 표시한 뒤 확인을 누릅니다. 경고 창이 뜨면 추가 정보 → 실행을 고릅니다. hta는 윈도우에서만 열립니다.

한글이 “파일에 접근하려고 합니다” 창을 띄워요

모두 허용을 누르면 됩니다. 보통은 변환기가 이 창이 뜨지 않게 처리합니다.

변환기 없이 할 수는 없나요

한두 개라면 한글에서 다른 이름으로 저장 → 파일 형식 hwpx로 저장하면 됩니다. 클로드에게 시켜도 됩니다.

이 폴더의 hwp 파일을 모두 hwpx로 바꿔서 “변환” 폴더에 넣어 줘. 원본은 그대로 둬.

6파일이 아닌 소스 가져오기

소스주는 방법
누리집 글주소를 붙여 넣고 “이 글을 읽고 …해 줘”라고 말합니다
로그인해야 보이는 화면크롬을 연결해 클로드가 내 브라우저로 읽게 합니다 (크롬 연결과 주의점 참고)
구글 드라이브 문서PC로 내려받아 경로로 주는 것이 가장 확실합니다
패들렛·게시판의 첨부“첨부 파일을 모두 내려받아 폴더에 정리해 줘”라고 먼저 시킨 뒤, 그 폴더를 소스로 씁니다
긴 글·오류 문구그대로 붙여 넣습니다. 아주 길면 txt로 저장해 경로로 줍니다

누리집에서 가져온 내용은 날짜와 수치를 원문과 한 번 대조합니다.

7소스 폴더 관리하기 오래 쓰려면

일 하나에 폴더 하나를 두고, 그 안을 세 칸으로 나눠 두면 클로드도 사람도 헷갈리지 않습니다.

2026 평가계획 ├ 원본 받은 그대로. 고치지 않는다 ├ 소스 hwpx·PDF로 바꾼 것, 갈무리한 그림 ├ 결과 클로드가 만든 것 └ 작업 기록.md
  • 원본은 고치지 않습니다. 클로드에게도 “원본 폴더는 읽기만 해”라고 말해 둡니다.
  • 파일 이름에 내용과 날짜를 넣습니다. 문서1.hwpx보다 2026 1학기 평가계획(0302).hwpx가 찾기 쉽습니다.
  • 무엇이 어디서 왔는지 적어 둡니다. 클로드에게 맡기면 됩니다.
  • 최신본이 무엇인지 알려 줍니다. 비슷한 파일이 여러 개면 클로드가 옛것을 읽을 수 있습니다.
이 폴더를 원본·소스·결과 세 폴더로 정리해 줘. 옮기기 전에 어떻게 옮길지 목록부터 보여 줘.
소스 폴더에 있는 파일마다 무엇인지, 어디서 받았는지 한 줄씩 적어서 “소스 목록.md”로 저장해 줘. 모르는 것은 비워 두고 나에게 물어봐.
비슷한 이름의 파일이 여러 개 있어. 고친 날짜와 내용을 비교해서 어느 것이 최신본인지 알려 줘.

원드라이브 폴더를 쓸 때

  • 구름 모양이 붙은 파일은 아직 PC에 없는 파일입니다. 폴더를 오른쪽 단추로 눌러 이 디바이스에 항상 유지를 골라 두면 읽다가 멈추지 않습니다.
  • 클로드가 파일을 잘못 고쳤을 때는 파일을 오른쪽 단추로 눌러 버전 기록에서 되살릴 수 있습니다.
  • 한글·엑셀·파워포인트에서 열어 둔 파일은 클로드가 고치지 못합니다. 닫고 시킵니다.
소스로 주기 전에 확인하세요
  • 학생 이름·연락처·성적·상담 내용이 든 파일은 그대로 주지 않습니다. 이름을 지우거나 번호로 바꾼 사본을 줍니다.
  • 폴더를 통째로 줄 때는 그 안에 개인정보 파일이 섞여 있지 않은지 먼저 봅니다.
  • 비밀번호나 API 키가 적힌 파일은 소스 폴더에 두지 않습니다.
  • 남이 만든 자료는 출처와 이용 조건을 적어 둡니다.
  • 경로를 주면 클로드는 그 파일을 고칠 수도 있습니다. 읽기만 시킬 때는 “고치지 마”를 붙입니다.
