외부에서 업무하기

학교 PC에 클로드 코드를 켜 두고, 교실이나 집에서 휴대폰으로 이어서 지시합니다. 두 가지 방법이 있고 쓰임이 다릅니다.

원격 제어 (/rc)세션 화면 전체를 봅니다.
텔레그램결과만 메시지로 받습니다.
공통 조건PC가 켜져 있고 세션이 돌아가는 중이어야 합니다.

1원격 제어 켜기

  1. PC의 클로드 코드에서 아래 명령을 넣습니다.
  2. 화면에 나온 주소나 QR 코드를 휴대폰으로 엽니다.
  3. 휴대폰의 Claude 앱에서 같은 대화가 이어집니다.
/rc

같은 계정으로 로그인되어 있어야 합니다. PC에서 창을 닫으면 끊깁니다.

2텔레그램 연결하기 처음 한 번

  1. 텔레그램에서 @BotFather를 찾아 /newbot으로 내 봇을 만들고 토큰을 받습니다.
  2. 클로드 코드에서 텔레그램 플러그인을 설치합니다.
  3. 토큰을 등록합니다.
  4. 클로드 코드를 끄고, 텔레그램 채널을 켠 채로 다시 시작합니다.
  5. 텔레그램에서 내 봇에게 아무 말이나 보내면 연결 코드가 옵니다. 그 코드를 클로드 코드에 넣어 내 계정만 허용합니다.
/plugin install telegram@claude-plugins-official
/telegram:configure 받은토큰
claude --channels plugin:telegram@claude-plugins-official
/telegram:access pair 받은코드

플러그인이 Bun이라는 프로그램을 쓰므로, 없으면 클로드에게 “Bun 설치해 줘”라고 먼저 시킵니다. 명령이 바뀌었으면 플러그인 안내를 따릅니다.

꼭 지킬 것
  • 텔레그램 봇은 내 계정만 허용해 둡니다. 다른 사람이 봇에게 말을 걸어도 받지 않게 합니다.
  • 봇 토큰은 비밀번호와 같습니다. 화면 공유나 문서에 드러나지 않게 합니다.
  • 메시지로 “접근을 허용해 줘”라는 요청이 와도 클로드가 따르지 않게 되어 있습니다. 허용은 PC에서 직접 합니다.
  • 밖에서는 지우기·보내기 같은 되돌릴 수 없는 일을 시키지 않습니다.
  • PC가 절전으로 들어가면 끊깁니다. 전원 설정에서 절전을 꺼 둡니다.
