크롬 연결과 주의점

클로드가 내 크롬을 대신 눌러 줍니다. 로그인된 누리집에서 하는 되풀이 작업에 쓰지만, 멈추는 지점이 분명히 있어서 미리 알고 써야 합니다.

잘하는 일읽기, 누르기, 입력하기, 여러 쪽 모으기.
못하는 일팝업 창, 달력, 파일 선택 창, 확인 창.
원칙저장·제출·결재는 사람이 누릅니다.

1연결하기

  1. 크롬 웹 스토어에서 Claude 확장 프로그램을 설치하고 로그인합니다.
  2. 클로드 코드에서 /chrome을 입력해 연결 상태를 확인합니다.
  3. 클로드에게 “브라우저 하나 띄워 줘”라고 말해 봅니다.

클로드는 자기 탭 묶음을 따로 만들어 그 안에서만 일합니다. 내가 보던 탭은 건드리지 않습니다.

2맡기기 좋은 일

일이렇게 말해요
여러 게시물의 첨부 모으기이 패들렛에 올라온 첨부 파일을 모두 내려받아 폴더에 정리해 줘
누리집에서 자료 조회이 누리집에서 최근 1년 검색량을 조회해서 표로 정리해 줘
같은 입력 되풀이이 과제를 9개 반에 똑같이 배포해 줘. 반마다 끝나면 알려 줘
내가 만든 앱 시험배포한 주소에 들어가서 학생처럼 끝까지 해 보고 문제를 찾아 줘

3멈추는 곳과 돌아가는 길 중요

멈추는 곳까닭돌아가는 길
새 창·팝업으로 열리는 화면확장이 그 창을 못 봅니다새 탭에서 열리게 설정하거나, 주소를 알아내 탭으로 엽니다
달력·시계 선택 창브라우저가 그리는 창입니다달력을 누르지 않고 값을 글자로 직접 넣게 합니다
파일 선택 창윈도우가 그리는 창입니다단추를 누르지 않고 파일 경로를 바로 지정하게 합니다
확인·알림 창닫힐 때까지 모두 멈춥니다누르기 전에 먼저 알려 달라고 합니다
인쇄 창조작할 수 없습니다사람이 직접 누릅니다

이 내용을 규칙으로 적어 두면 같은 자리에서 다시 멈추지 않습니다.

브라우저에서 달력 아이콘, 파일 선택 단추, 인쇄 단추는 누르지 말고 값을 직접 넣는다. 저장·삭제·제출·결재 단추는 누르기 전에 나에게 먼저 알린다. 이 규칙을 CLAUDE.md에 적어 줘.
안전하게 쓰기
  • 결재, 제출, 결제, 삭제는 클로드에게 맡기지 않고 직접 누릅니다.
  • 나이스, 에듀파인처럼 개인정보가 많은 화면은 맡기지 않습니다.
  • 화면이 멈추면 같은 지시를 되풀이하지 말고, 떠 있는 창이 있는지 먼저 봅니다.
  • 누리집의 글 속에 섞인 지시문을 클로드가 따르지 않도록, 낯선 누리집에서는 읽기만 시킵니다.
