1파이어베이스 프로젝트 만들기 앱마다 한 번

  1. console.firebase.google.com에 구글 계정으로 들어갑니다.
  2. 프로젝트 만들기를 누르고 이름을 정합니다. 예: guwol-quiz
  3. 이름 아래에 보이는 프로젝트 ID를 적어 둡니다. 게시 주소가 프로젝트ID.web.app이 됩니다.
  4. 구글 애널리틱스는 꺼도 됩니다.

학교 구글 계정에서 프로젝트 만들기가 막혀 있으면 개인 구글 계정으로 만듭니다.

2쓸 기능 켜기 콘솔에서 직접

왼쪽 메뉴의 빌드에서 필요한 것만 켭니다.

기능하는 일켤 때
Firestore Database자료 저장데이터베이스 만들기 → 위치 asia-northeast3 (서울)
Authentication로그인필요할 때만. 익명 로그인이 가장 간단합니다
Hosting화면 게시따로 켤 것 없이 배포하면 생깁니다

데이터베이스 위치는 한번 정하면 바꿀 수 없습니다. 처음에 서울로 고릅니다.

3도구 설치하기 한 번만

Node.js와 파이어베이스 CLI(firebase-tools)가 설치되어 있는지 확인하고, 없으면 설치해 줘.

직접 설치하려면 파워셸에 넣습니다.

winget install --id OpenJS.NodeJS.LTS -e
npm install -g firebase-tools

Node.js를 설치한 뒤 파워셸 창을 새로 열고 둘째 줄을 넣습니다.

4파이어베이스에 로그인하기 한 번만 · 직접 해야 해요

새 파워셸 창에서 아래 명령을 넣습니다. 브라우저가 열리면 1번에서 쓴 구글 계정을 고르고 허용을 누릅니다.

firebase login

잘 됐는지 확인합니다. 1번에서 만든 프로젝트가 목록에 보이면 연결된 것입니다.

firebase projects:list

5클로드에게 만들고 배포해 달라고 하기

새로 만들 때

파이어베이스 프로젝트 guwol-quiz에 올릴 퀴즈 앱을 만들어 줘. 학생이 이름을 넣고 답을 내면 순위표가 실시간으로 바뀌게 하고, 호스팅으로 배포한 뒤 주소를 알려 줘.

이미 있는 앱을 옮길 때

이 폴더의 구글 앱스스크립트 앱을 파이어베이스 프로젝트 guwol-quiz로 옮겨 줘. 기능은 그대로 두고, 배포까지 해 줘.

고친 뒤

방금 고친 내용을 배포해 줘.

게시 주소는 이런 모양입니다.

https://프로젝트ID.web.app

6보안 규칙 확인하기 꼭

데이터베이스는 보안 규칙으로 “누가 무엇을 읽고 쓸 수 있는지”를 정합니다. 규칙이 열려 있으면 주소를 아는 누구나 자료를 읽고 지울 수 있습니다.

지금 보안 규칙을 쉬운 말로 설명해 줘. 학생은 자기 기록만 쓸 수 있고, 다른 학생 기록은 고치지 못하게 해 줘.
  • ‘테스트 모드’로 만들면 30일 뒤 자동으로 닫혀 앱이 갑자기 멈춥니다. 수업 전에 규칙을 정해 둡니다.
  • 규칙을 바꾼 뒤에는 클로드에게 “다른 학생인 척 접속해서 막히는지 시험해 줘”라고 확인시킵니다.
자료를 넣기 전에 꼭 확인하세요
  • 학생 실명, 학번, 생년월일을 그대로 저장하지 않습니다. 꼭 필요하면 최소한만 넣고, 행사가 끝나면 지웁니다.
  • 서비스 계정 키(json 파일)는 누구에게도 주지 않고, 깃허브에 올리지 않습니다.
  • 화면 코드에 들어가는 apiKey는 공개되어도 되는 식별 값입니다. 실제 방어는 보안 규칙이 합니다.
  • 무료 요금제에는 하루 사용량 한도가 있습니다. 전교생이 한꺼번에 쓰는 행사라면 클로드에게 “무료 한도 안에 들어오는지 계산해 줘”라고 미리 물어봅니다.

?막혔을 때

npm이나 firebase를 실행하면 “스크립트를 실행할 수 없습니다”가 나와요

윈도우 파워셸의 기본 설정 때문입니다. 아래 명령을 한 번 넣고 Y를 누릅니다.

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
firebase 명령을 찾을 수 없다고 나와요

설치한 뒤 파워셸 창을 새로 열지 않았을 때 생깁니다. 창과 클로드 코드를 닫았다가 다시 엽니다.

프로젝트 목록에 내 프로젝트가 안 보여요

다른 구글 계정으로 로그인된 경우입니다. 아래 명령으로 나갔다가 다시 로그인합니다.

firebase logout
firebase login
배포했는데 화면이 그대로예요

브라우저가 옛 화면을 기억하고 있을 때입니다. Ctrl+F5로 새로 고칩니다.

권한 오류(permission denied)가 나와요

보안 규칙이 막고 있다는 뜻입니다. 오류 문구를 그대로 클로드에게 붙여 넣고 “규칙 때문인지 확인해 줘”라고 말합니다.
