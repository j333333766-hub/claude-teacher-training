엑셀·파워포인트 연결하기

엑셀과 파워포인트에 클로드를 추가 기능으로 넣으면, 파일을 올리지 않고 열어 둔 문서 옆에서 바로 시킬 수 있습니다. 클로드가 시트와 슬라이드를 직접 읽고 고칩니다.

1쓸 수 있는지 먼저 확인하기 중요

확인할 것되는 경우안 되는 경우
클로드 요금제Pro, Max, Team, Enterprise무료
오피스 종류Microsoft 365 구독판(윈도우·맥), 웹용 오피스오피스 2016·2019 같은 영구 사용권 제품, 아이패드, 안드로이드
계정 설정추가 기능 설치가 허용된 계정학교·기관 계정에서 관리자가 스토어를 막아 둔 경우

학교 PC의 오피스가 2016·2019라면 설치형에서는 쓸 수 없습니다. 이럴 때는 브라우저에서 office.com에 들어가 웹용 엑셀·파워포인트에서 씁니다.

내 오피스가 구독판인지 보려면 엑셀에서 파일 → 계정을 엽니다. 제품 정보에 Microsoft 365라고 적혀 있으면 구독판입니다.

2추가 기능 설치하기 한 번만

  1. 마이크로소프트 마켓플레이스의 Claude for Microsoft 365 페이지를 엽니다.
  2. Get it now(지금 받기)를 누릅니다. 마이크로소프트 계정으로 로그인하라는 화면이 나오면 오피스에 쓰는 계정으로 로그인합니다.
  3. 엑셀이나 파워포인트를 엽니다.
  4. 홈 → 추가 기능에서 Claude를 눌러 켭니다. (맥은 도구 → 추가 기능)
  5. 오른쪽에 열린 창에서 클로드 계정으로 로그인합니다.

한 번 설치하면 엑셀과 파워포인트에 함께 들어옵니다. 다음부터는 홈 탭의 Claude 단추만 누르면 됩니다.

마켓플레이스 페이지를 찾기 어려우면, 엑셀의 홈 → 추가 기능 → 추가 기능 더 보기에서 Claude를 검색해도 됩니다.

3엑셀에서 쓰기

파일을 연 채로 오른쪽 창에 말하면, 클로드가 그 통합 문서를 읽고 고칩니다. 답에 적힌 셀 주소를 누르면 그 셀로 이동합니다.

하고 싶은 일이렇게 말해요
구조 파악이 통합 문서에 어떤 시트가 있고 서로 어떻게 이어져 있는지 설명해 줘
계산 과정 확인F12 셀의 값이 어떻게 계산된 것인지 차례대로 설명해 줘
검산교과군별 시수 합계가 맞는지 검산하고, 안 맞는 줄을 알려 줘. 고치지는 마
오류 찾기요약 시트의 #REF! 오류가 어디서 생겼는지 찾아 줘
수식 만들기반별 평균과 표준편차를 구하는 수식을 H열과 I열에 넣어 줘
표 정리점수가 60점 미만인 칸에 색을 넣고, 반 열에 드롭다운 목록을 만들어 줘
차트반별 평균을 막대 차트로 만들어 새 시트에 넣어 줘
이 편성표에서 3개 학년의 교과군별 시수 합계를 검산해 줘. 기준 시수와 다른 곳은 셀 주소와 함께 표로 보여 주고, 아직 아무것도 고치지 마.

정렬, 필터, 피벗 테이블 고치기, 조건부 서식, 드롭다운 만들기는 됩니다. 매크로(VBA)와 데이터 표 기능은 다루지 못합니다.

4파워포인트에서 쓰기

내 서식을 먼저 입혀 두고 시킵니다. 클로드가 슬라이드 마스터의 배치·글꼴·색을 읽어 그 틀에 맞춰 만듭니다.

하고 싶은 일이렇게 말해요
초안 만들기학부모 설명회 자료를 10쪽으로 만들어 줘. 일정, 평가 방법, 준비물, 문의처 순서로
한 쪽만 고치기3쪽 글이 너무 많아. 한 줄 글머리표 네 개로 줄여 줘
도해로 바꾸기이 쪽의 글머리표를 순서도로 바꿔 줘
차트 넣기이 표로 막대 차트를 만들어 줘. 나중에 내가 고칠 수 있는 차트로
순서 다듬기4~7쪽의 흐름을 결론부터 말하는 순서로 바꿔 줘
차례 만들기지금 구성에 맞는 차례 쪽을 맨 앞에 넣어 줘
이 서식 그대로, 1학기 수행평가 안내를 6쪽으로 만들어 줘. 쪽마다 제목 한 줄과 글머리표 세 개 이내로 하고, 날짜와 배점은 내가 채울 수 있게 빈칸으로 둬.

전체를 다시 만들게 하지 말고 “○쪽만”이라고 짚어 줍니다. 손으로 다듬은 다른 쪽이 그대로 남습니다.

5엑셀과 파워포인트를 함께 쓰기

두 프로그램의 클로드는 대화를 함께 씁니다. 엑셀과 파워포인트를 둘 다 열어 두면 엑셀의 표를 발표 자료로 옮기는 일을 한 번에 시킬 수 있습니다.

엑셀에 열려 있는 설문 결과 시트로, 파워포인트에 문항별 결과 차트 슬라이드를 한 쪽씩 만들어 줘.

6늘 지킬 규칙 적어 두기

오른쪽 창의 Settings → Instructions에 적어 두면 대화마다 다시 말하지 않아도 됩니다. 엑셀과 파워포인트는 따로 적습니다.

프로그램적어 둘 만한 것
엑셀숫자에는 천 단위 쉼표를 넣는다. 머리글은 굵게 한다. 고치기 전에 무엇을 고칠지 먼저 말한다
파워포인트글머리표는 한 줄로 쓴다. 한 쪽에 글머리표는 네 개까지. 강조는 서식의 강조색만 쓴다

7추가 기능과 클로드 코드, 언제 무엇을 쓰나요

상황알맞은 것
열어 둔 파일 하나를 보면서 고칠 때엑셀·파워포인트 추가 기능
수식·차트·슬라이드를 프로그램 기능 그대로 만들고 싶을 때엑셀·파워포인트 추가 기능
파일 여러 개를 한꺼번에 처리할 때 (30개 반 명렬표 합치기 등)클로드 코드
한글(hwpx)·PDF·그림과 엮어서 일할 때클로드 코드
오피스가 구독판이 아니라 추가 기능을 못 쓸 때클로드 코드 또는 웹용 오피스

클로드 코드에게 시킬 때는 파일 경로를 주고, 그 파일은 엑셀·파워포인트에서 닫아 둡니다. 추가 기능은 반대로 파일을 열어 둔 채 씁니다.

쓰기 전에 알아 두세요
  • 사본으로 시작합니다. 넓게 고치게 할 때는 파일을 복사해 두고 사본에서 시킵니다.
  • 결과는 사람이 검토합니다. 합계, 인원, 날짜처럼 틀리면 안 되는 수치는 원자료와 대조합니다.
  • 믿을 수 있는 파일에서만 씁니다. 바깥에서 받은 파일에는 클로드를 속이는 숨은 지시문이 들어 있을 수 있습니다.
  • 확인 창을 읽고 누릅니다. 기존 자료를 덮어쓰기 전에 클로드가 물어봅니다.
  • 학생 개인정보가 든 파일(성적, 연락처, 상담 기록)은 이름을 지우거나 번호로 바꾼 사본으로 씁니다. 파일 내용은 클로드 서버로 보내져 처리됩니다.
  • 사용량은 클로드 계정과 함께 셉니다. 큰 파일을 오래 다루면 한도에 빨리 닿습니다.

?막혔을 때

홈 탭에 추가 기능 단추나 Claude가 안 보여요

오피스가 구독판이 아니거나 오래된 버전일 수 있습니다. 파일 → 계정에서 Microsoft 365인지 보고, 업데이트 옵션 → 지금 업데이트를 누릅니다. 그래도 없으면 웹용 오피스에서 씁니다.

“관리자가 차단했습니다”라고 나와요

학교·기관의 Microsoft 365 계정은 관리자가 추가 기능 설치를 막아 두는 경우가 많습니다. 개인 Microsoft 365 계정으로 하거나, 관리자에게 Claude for Microsoft 365 배포를 요청합니다.

로그인했는데 쓸 수 없다고 나와요

클로드 계정이 무료 요금제인 경우입니다. 추가 기능은 Pro 이상에서 쓸 수 있습니다.

지난 대화가 다른 PC에서 안 보여요

대화 기록은 그 PC에만 저장됩니다. 이어서 할 내용은 파일 안에 메모 시트나 메모 쪽으로 남겨 둡니다.

한글(hwp)에서도 쓸 수 있나요

한글용 추가 기능은 없습니다. 한글 문서는 hwpx로 바꿔 클로드 코드나 데스크탑앱에서 다룹니다. (소스 가져오기 참고)
