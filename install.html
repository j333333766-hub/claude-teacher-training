클로드 코드 준비 ①

필수 프로그램 설치하기

클로드 코드는 내 PC에 깔린 프로그램을 불러서 일합니다. 아래 네 가지만 있으면 연수에서 다루는 작업은 거의 다 됩니다.

무엇을 하나요Git, Node.js, Python, 클로드 코드를 설치하고 확인합니다.
걸리는 시간20분쯤. 한 번만 하면 됩니다.
필요한 것윈도우 10·11 PC, 인터넷, 설치 권한.
프로그램무엇에 쓰나요없으면
Git바뀐 내용을 기록하고 깃허브에 올립니다. 윈도우에서는 클로드 코드가 돌아가는 데도 필요합니다클로드 코드가 제대로 실행되지 않습니다
Node.js · npm웹앱 도구(파이어베이스, 앱스스크립트 등)를 설치하고 실행합니다배포 도구를 쓸 수 없습니다
Python엑셀·한글·PDF·그림·영상 같은 파일을 다룹니다문서 자동화가 막힙니다
클로드 코드터미널에서 일하는 클로드입니다없음

1파워셸 열기

윈도우 키를 누르고 powershell을 입력해 Windows PowerShell을 엽니다. 아래 명령을 한 줄씩 붙여 넣고 Enter를 누릅니다.

설치 도중 “변경을 허용하시겠습니까?” 창이 뜨면 예를 누릅니다.

2Git 설치하기

winget install --id Git.Git -e

3Node.js 설치하기 npm이 함께 깔려요

winget install --id OpenJS.NodeJS.LTS -e

4Python 설치하기

winget install --id Python.Python.3.12 -e

5창을 닫았다가 다시 열고 확인하기 중요

설치한 프로그램은 새로 연 창에서만 잡힙니다. 파워셸을 닫고 다시 연 뒤, 한 줄씩 넣어 버전 숫자가 나오는지 봅니다.

git --version
node -v
npm -v
python --version

숫자가 나오면 설치된 것입니다. “용어가 인식되지 않습니다”가 나오면 그 프로그램만 다시 설치합니다.

6클로드 코드 설치하기

irm https://claude.ai/install.ps1 | iex

끝나면 파워셸을 새로 열고 아래 명령으로 시작합니다. 처음에는 브라우저가 열리며 로그인합니다.

claude

잘 깔렸는지는 claude --version, 문제가 있을 때는 claude doctor로 점검합니다.

7나머지는 클로드에게 시키기

여기까지 되면, 그다음 도구는 필요할 때 클로드에게 맡기면 됩니다.

내 PC에 git, node, npm, python, gh, firebase, clasp가 깔려 있는지 확인하고, 없는 것은 설치해 줘.
도구쓰는 곳
GitHub CLI (gh)깃허브에 올리고 게시하기
firebase-tools파이어베이스 배포
clasp구글 앱스스크립트 올리기·내려받기
ffmpeg영상 자르기·붙이기·자막 넣기

?막혔을 때

winget을 찾을 수 없다고 나와요

마이크로소프트 스토어에서 앱 설치 관리자(App Installer)를 업데이트합니다. 학교 PC에서 막혀 있으면 각 프로그램 누리집에서 설치 파일을 받습니다: Git, Node.js, Python.

npm을 실행하면 “스크립트를 실행할 수 없습니다”가 나와요

파워셸 기본 설정 때문입니다. 아래 명령을 한 번 넣고 Y를 누릅니다.

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
python을 넣으면 스토어가 열려요

윈도우의 가짜 바로가기 때문입니다. 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python 관련 항목 두 개를 끕니다.
