# 클로드를 활용한 교사 업무 혁명 — 연수 안내 사이트

2026. 10. 19.(월) 전학공 클로드 연수(구월중학교 조창현)에서 연수생에게 공유한 안내 페이지와 실습 자료입니다.

- 사이트: https://j333333766-hub.github.io/claude-teacher-training/
- `index.html` 첫 화면 · 안내 페이지 19쪽(`*.html`)
- `commands.html` 클로드 코드 실행 명령 모음 (파워셸에서 폴더 열기 → 시작 → 이어서 하기 → 허락 방식 → 한 번 묻기 → 뒤에서 돌리기 → 관리 → MCP·플러그인 → 짧은 명령 만들기 → 대화 안 명령, 106개)
- `practice.html` 연수 실습 다시 보기 — 연수 앱(Firebase)에서 한 퀴즈·실습 1~6·시연 영상·스킬 나눔을 정적 페이지로 옮긴 것
- `files/` 실습 파일(AI소스변환기, 공문 담당자 안내 스킬, 가상 업무분장표, 나이스·K-에듀파인 스킬 사본)
- `video/` 시연 영상 mp4 (유튜브에도 있음)

다른 연수에 다시 쓸 때는 `index.html`의 일시·장소와 맨 위 '연수를 마쳤습니다' 안내를 고치면 됩니다.
