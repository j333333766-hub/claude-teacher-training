앱스스크립트 연결하기

구글 시트와 붙여 쓰는 간단한 웹앱은 앱스스크립트가 가장 빠릅니다. clasp라는 도구로 연결하면 클로드가 내 PC에서 코드를 고쳐 바로 올립니다.

언제 쓰나요구글 시트에 기록이 쌓이는 신청·조사·기록 앱.
비용무료.
필요한 것구글 계정, Node.js, 클로드 코드.

1clasp 설치하기 한 번만

clasp가 설치되어 있는지 확인하고, 없으면 설치해 줘.

직접 설치하려면

npm install -g @google/clasp

2앱스스크립트 API 켜기 한 번만 · 직접

  1. script.google.com/home/usersettings에 들어갑니다.
  2. Google Apps Script API를 사용으로 바꿉니다.

이것을 켜지 않으면 올릴 때 오류가 납니다.

3로그인하기 한 번만 · 직접

새 파워셸 창에서 아래 명령을 넣고, 브라우저에서 구글 계정을 골라 허용합니다.

clasp login

구글 계정이 여러 개면, 앱을 만든 계정으로 로그인했는지 꼭 확인합니다.

4스크립트 ID 찾기

  1. 앱스스크립트 편집기를 엽니다.
  2. 왼쪽 톱니바퀴 프로젝트 설정을 누릅니다.
  3. 스크립트 ID를 복사합니다.

5클로드에게 맡기기

이미 있는 앱을 가져와 고칠 때

C:\Users\내이름\Documents\윷놀이 폴더에 앱스스크립트를 가져와서 고치고 배포하고 싶어. 스크립트 ID는 (붙여 넣기)야.

새로 만들 때

구글 시트에 응답이 쌓이는 신청 앱을 앱스스크립트로 만들어 줘. 학년·반·번호를 넣으면 이름이 뜨고, 선착순 30명까지만 받게 해 줘.

고친 뒤

고친 내용을 올리고, 지금 쓰는 배포 주소 그대로 다시 배포해 줘.

“같은 주소로 다시 배포”라고 말해야 학생에게 나눠 준 주소가 바뀌지 않습니다.

앱스스크립트의 한계
  • 동시에 많은 학생이 쓰면 느려지거나 멈출 수 있습니다. 전교생 행사는 파이어베이스가 낫습니다.
  • 검증받지 않은 웹앱은 사용자가 100명을 넘으면 새 사용자가 막힙니다.
  • 학교 계정으로 만든 앱은 학교 밖 계정에서 안 열릴 수 있습니다. 배포할 때 접근 범위를 확인합니다.
  • 구글 계정을 여러 개 로그인한 브라우저에서는 접속 오류가 날 수 있습니다. 시크릿 창에서 열어 봅니다.

?막혔을 때

올릴 때 권한 오류가 나와요

2번의 API를 켰는지, 앱을 만든 계정으로 로그인했는지 확인합니다. 계정을 바꾸려면

clasp logout
clasp login
배포했는데 화면이 그대로예요

코드만 올리고 배포를 새로 하지 않은 경우입니다. 클로드에게 “배포 버전까지 갱신해 줘”라고 말합니다.

시트 시간이 9시간 어긋나요

스크립트의 시간대 설정 때문입니다. 클로드에게 “시간대를 Asia/Seoul로 맞춰 줘”라고 말합니다.
